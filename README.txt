PROFILEVAULT v1.5 - DEPLOY GUIDE
================================

IN THIS ZIP
  index.html   The whole app (one file)
  README.txt   This guide

PUT IT ONLINE (first time)
  1. github.com > New repository (Private is fine).
  2. "Add file" > "Upload files": drop index.html (keep this exact name) > Commit.
  3. vercel.com > Add New > Project > pick the repository > Deploy.
  4. Open the link Vercel gives you.
  5. iPhone/iPad: Safari > Share > "Add to Home Screen", then open from the icon.

UPDATE LATER
  Upload the new index.html to the same GitHub repository (same name,
  it replaces the old one). Vercel redeploys in about a minute.
  Your saved data stays, because the address stays the same.

WHAT IS IN v1.5
  Home: search box, backup reminder, documents expiring soon, quick actions
  People: profile, photos, contacts, completeness checklist, timeline
  Records: education, experience, training, awards, skills, projects
           (each can carry certificates, uploaded while you fill the form)
  Documents: vault with previews, categories, tags, expiry dates, links to records
  Search: people, records, documents, contacts, #tags (Home box or Search tab)
  Resume: choose sections/items/filters, live A4 preview, saved presets,
          Save as PDF (print), saved copies, Excel export
  NEW in v1.5: Teacher's / recommendation letters and Portfolio link on the checklists;
          shortcuts to Current work & study on the resume page and person page.
  Earlier in v1.4: Application package (checklist for speaker, job or scholarship/school,
          then download the resume and chosen documents as one zip).
  Earlier in v1.3: Team size and Budget / scale fields on experience and projects.
  Earlier in v1.2: record types Languages, Activities, Publications, Talks,
          Memberships, References; resume types Speaker profile, Job / promotion
          application, Scholarship / school application.
  Earlier in v1.1: person profile has "Current work & study"; resume has a
          "Current position / study" section and an "Address to show" picker.
  Settings: language (English/Thai), backup & restore, recently deleted

KEEP YOUR DATA SAFE
  Data lives inside the browser on each device. Make a backup:
  Settings > Backup > Create backup > Save / share (iPhone: Save to Files).
  Keep copies in two places. Move data between devices with
  Settings > Restore > Merge.
  Use a passphrase for backups that hold ID numbers - and remember it.

FOR FUTURE CHANGES
  See HANDOFF.md (in the handoff zip). Upload it with index.html to a
  new conversation and describe the change you want.
